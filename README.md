## 代表作：《宫廷理发师》HeirCut

叙事解谜游戏（Unity 6），6 人团队中唯一的程序。源码在团队私有仓库，开发过程写成了 12 篇开发手记。

- 获 CUSGA 最佳剧情设计奖、厦门国际动漫节金海豚奖「最佳学生游戏奖」、「指尖星图」叙事与沉浸体验赛道优胜奖
- 展出于 2025 深圳动漫节、2026 ChinaJoy
- [Steam 商店页](https://store.steampowered.com/app/4268650/) · [演示视频](https://www.bilibili.com/video/BV1dkbDzoE9q/) · [开发手记（12 篇）](https://yufenghuang.tech/series/heircut-%E5%BC%80%E5%8F%91%E6%89%8B%E8%AE%B0/)

技术要点：

- 数据驱动的剧情架构，剧情逻辑与引擎解耦，全项目 700+ 项自动化测试
- React + React Flow 节点图剧情编辑器，导入时 103 种静态诊断
- 离线推演工具与游戏内机器人交叉验证整局可达性
- 实时 2D 剪发：Clipper2 布尔运算 + Poly2Tri 重建网格
- 安装包 2.2 GB → 860 MB，首次进场景最差帧 1744 ms → 121 ms（编辑器实测）
